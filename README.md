# ClickGame

> The name will probably be changed if I keep working on the project.

A very simple game written entirely in C using [raylib](https://www.raylib.com/).

All you have to do is click the shapes and get a good score before the timer runs out.

I might make the game harder in the future and add more precision-based mechanics, turning it into something closer to an aim trainer.

## Compile

```bash
make
```

## Run

```bash
./game
```

## Clean the build

```bash
make clean
```

## Controls

Just the mouse.

## Important

> **You may need to recompile `external/libraylib.a` for your system.**
